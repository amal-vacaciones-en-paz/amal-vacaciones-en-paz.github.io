# AMAL Vacaciones en Paz — web inicial

Web estática responsive en HTML, CSS y JavaScript. No necesita base de datos ni servidor propio.

## Antes de publicar
1. Abre `index.html` y sustituye todos los textos `CAMBIAR-POR-CORREO-OFICIAL`, `AÑADIR LOCALIDAD DE AMAL` y `AÑADIR ENLACES OFICIALES`.
2. En el bloque JSON-LD, sustituye `https://example.org/` por la URL pública real. Elimina `nonprofitStatus` si no corresponde a una clasificación verificada.
3. Añade datos reales de la asociación, número de registro, domicilio de contacto y aviso legal, privacidad y cookies según proceda.
4. Comprueba la historia, requisitos de acogida y afirmaciones humanitarias con fuentes oficiales recientes.
5. **Donaciones:** el botón es solo un enlace de contacto provisional. Sustitúyelo por el enlace oficial de donación creado desde la cuenta de pagos de la asociación, tras la verificación del proveedor. No recojas datos bancarios en esta web.
6. Las tipografías se cargan desde Google Fonts; si prefieres no usar recursos externos, elimina el `@import` de `styles.css`.

## Probar localmente
Haz doble clic en `index.html` para abrirlo en el navegador.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio público, por ejemplo `amal-vacaciones-en-paz`.
3. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
4. En el repositorio abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. GitHub mostrará la URL pública cuando termine el despliegue.
7. En la URL pública comprueba todos los enlaces y la visualización en móvil.

El alojamiento de GitHub Pages está disponible gratis para repositorios públicos en el plan Free. No se ha publicado esta web por ti ni se ha reservado un dominio; la URL solo existirá después de que completes estos pasos.

## Aparecer en Google
1. Cuando la web esté publicada, abre Google Search Console: https://search.google.com/search-console/
2. Añade la URL pública como propiedad de tipo prefijo de URL.
3. Sigue el método de verificación disponible para tu alojamiento.
4. Usa Inspección de URL para solicitar indexación de la página principal.
5. Comprueba más adelante `site:TU-URL-PUBLICA` en Google.

La indexación no es instantánea ni está garantizada. Para mejorar la visibilidad, completa los datos reales de AMAL, usa títulos descriptivos, mantén la web actualizada y solicita a colaboradores que enlacen la web oficial.

## Donaciones y transparencia
- Usa una cuenta de pago a nombre de AMAL, no la cuenta personal de un miembro.
- Verifica la entidad con el proveedor (por ejemplo, PayPal) y confirma las comisiones antes de anunciar el botón.
- Publica claramente el destino de los fondos, quién los administra y cómo se rinden cuentas.
- No prometas deducciones fiscales sin confirmar que la entidad cumple todos los requisitos legales aplicables.
